# Functional Analysis Cases 3 and 4

Repository contents:

- `Отчет_кейсы_3_4.pdf` - final report for cases 3 and 4.
- `Отчет_кейсы_3_4.md` - report source.
- `кейс3.ipynb` - computations for case 3.
- `кейс4.ipynb` - computations for case 4.
- `functional_rto_case4_submit.py` - reproducible script for the case 4 final prediction.
- `test.csv` - final prediction file for case 4.
- `figures_case3/`, `figures_case4/`, `report_static_figures/` - generated plots used by notebooks and report.
- `case3_worldcities_summary.json`, `functional_rto_case4_report.json` - compact run summaries.

Large source datasets are intentionally not committed.
